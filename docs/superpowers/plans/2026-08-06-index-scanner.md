# Index Scanner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `plumb index` scans the repository's tracked source files for public symbols and regenerates `.plumb/index.md` — the "what this repo can already do, and where" artefact — and `plumb check --diff` warns when the committed index no longer matches a fresh scan.

**Architecture:** Symbol extraction and index rendering are pure and live in `plumb-core` (`index::symbols` per-file line matchers in the same heuristic family as `boundaries::imports`; `index::render` produces the deterministic document). `plumb-cli` supplies the file list via a new `git::tracked_files` (from `git ls-files -z` — tracked files only, so ignores are respected and the scan is reproducible) and owns the `index` subcommand plus the staleness finding in `check`. A placeholder index (never scanned) is not stale: staleness only applies once the index carries the scanner's own marker.

**Tech Stack:** Rust 1.97, edition 2024. No new dependencies.

## Contract details shared by the tasks

**Symbol extraction (line-based heuristic, same family and honesty as `boundaries::imports`):** on each trimmed line —
- `.rs`: lines starting `pub fn`, `pub struct`, `pub enum`, `pub trait`, `pub const`, `pub static`, `pub mod`, `pub type` → kind is the keyword after `pub` (e.g. `fn`), name is the following identifier (stops at `(`, `<`, `:`, `;`, `=`, `{`, whitespace). `pub(crate)`/`pub(super)` are NOT public — skip. Lines deeper than top level are naturally included if they start with `pub` after trimming — accepted noise, documented (an impl's `pub fn` IS part of the public surface anyway).
- `.py`: top-level (no leading whitespace on the raw line) `def NAME(` and `class NAME` where NAME does not start with `_` → kinds `def`/`class`.
- `.ts`/`.tsx`/`.js`/`.jsx`/`.mjs`/`.cjs`: lines starting `export function NAME`, `export async function NAME`, `export class NAME`, `export const NAME`, `export let NAME`, `export interface NAME`, `export type NAME`, `export enum NAME`, `export default function NAME` → kind is the declaration keyword, name as above. Bare `export {` / `export default` without a following declaration keyword and name → skipped (re-exports carry no local definition to point at).
- Other extensions → empty.

**Index document shape** (deterministic; entries sorted by path, symbols in source order):

```markdown
# Index

<!-- generated by `plumb index`; do not edit by hand -->

What this repository can already do, and where. Regenerate with
`plumb index` after the public surface changes.

## <path/to/file.rs>

- fn `name`
- struct `Name`
```

Files with no symbols get no section. `SCAN_MARKER` is the exact string ``generated by `plumb index` `` — its presence distinguishes a scanned index from the never-scanned placeholder (whose marker line is `<!-- generated: do not edit by hand -->`), and staleness applies only to a scanned index.

**Staleness rule:** in `check --diff`, when `.plumb/index.md` exists AND contains `SCAN_MARKER`: recompute the index in memory from tracked files and compare line-ending-insensitively (same normalisation as the drift gate). Differ → one Tier B finding `index-stale`, location `.plumb/index.md`, message naming `plumb index` as the remedy, source `taxonomy §11`. Placeholder or missing index → silent.

Follow the "Contract details" section. Sketch of the Rust matcher (the others follow the same shape):

```rust
const RUST_KINDS: &[&str] = &[
    "fn", "struct", "enum", "trait", "const", "static", "mod", "type",
];

fn rust_symbol(line: &str) -> Option<Symbol> {
    let rest = line.trim_start().strip_prefix("pub ")?;
    // `pub(crate)`/`pub(super)` never reach here: their prefix is `pub(`,
    // not `pub `, so the strip above already rejected them.
    let (kind, rest) = RUST_KINDS.iter().find_map(|kind| {
        rest.strip_prefix(kind)
            .filter(|tail| tail.starts_with(|c: char| c.is_whitespace()))
            .map(|tail| (*kind, tail))
    })?;
    let name = identifier(rest.trim_start());
    (!name.is_empty()).then(|| Symbol {
        kind: kind.to_string(),
        name,
    })
}

fn identifier(text: &str) -> String {
    text.chars()
        .take_while(|c| c.is_alphanumeric() || *c == '_')
        .collect()
}
```

`render`: sort a cloned entry list by path, skip empties, emit the document per the contract shape. Reuse the `extension()` logic style from `boundaries.rs` (lowercased, dotless → empty) — copy the private helper rather than making it public unless clippy pushes otherwise; a one-line duplication beats widening plumb-core's API for it.
