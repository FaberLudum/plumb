# pub.dev Gate Implementation Plan (PR D)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The `package-exists` gate covers pub.dev: every package a change adds to a `pubspec.yaml` must exist on pub.dev — with `sdk:`/`git:`/`path:` dependencies never looked up, because they do not live there.

**Architecture:** Fourth ecosystem on the `EcosystemSpec` seam, same mould as NuGet (PR #26): one spec file `ecosystems/pub.rs` + table line in plumb-core; one `PubRegistry` + router arm in plumb-cli. YAML parsed with `yaml-rust2` (new dependency: 0.11.0, 50M downloads, YAML 1.2, chosen over saphyr 0.0.x for maturity — verify exact current version at implementation time). Spec: `docs/superpowers/specs/2026-08-11-nuget-pub-ecosystems-design.md`, pub.dev section.

**Tech Stack:** Rust 1.97 edition 2024; `yaml-rust2` (verify with `cargo add yaml-rust2 -p plumb-core --dry-run`).

### Task 1: `Ecosystem::Pub` and the pubspec reader

**Files:**
- Create: `crates/plumb-core/src/ecosystems/pub_dev.rs` (module name `pub` is a Rust keyword — file and module are `pub_dev`, the struct is `PubDev`)

- Modify: `crates/plumb-core/src/manifest.rs` (add `Ecosystem::Pub`; add `Gap::HostedElsewhere(String)` with a `describe` arm — a `hosted:` block naming a custom URL, the private-registry class)
- Modify: `crates/plumb-core/Cargo.toml` + `Cargo.lock` (add `yaml-rust2`)
- Modify: `docs/dependencies.md` (row: stdlib has no YAML; pubspec's nested block shapes — `sdk:`, `git:`, `path:`, `hosted:` — are exactly what an indentation heuristic gets wrong, and this gate blocks)

**Interfaces:**
- Consumes: `EcosystemSpec` trait (`ecosystem()`, `matches(filename)`, `parse(filename, text)`), the table, `Manifest`/`Gap` — read `ecosystems/nuget.rs` (the freshest consumer) for the mould.
- Produces: `pub struct PubDev;` in `ALL`; `Ecosystem::Pub` for Task 2. `matches`: exactly `pubspec.yaml` (case-insensitive). Reads sections `dependencies`, `dev_dependencies`, `dependency_overrides` of the top-level mapping.

Per-entry rule (the heart of this task — a dependency's VALUE decides whether it is a lookup):
- Scalar string (`dio: ^5.9.2`) or null/empty value → registry-hosted → name collected.
- Mapping containing `sdk` (`flutter: {sdk: flutter}`) → never a lookup, no gap (correct, not unread).
- Mapping containing `git` or `path` → never a lookup, no gap.
- Mapping containing `hosted` whose value is a mapping with a `url` (or a scalar custom host) → `Gap::HostedElsewhere(name)`, no lookup.
- Mapping containing `hosted` naming the default pub.dev host, or a `version`-only mapping (`dio: {version: ^5.9.2}`) → name collected.
- Any other mapping shape → `Gap::Malformed`-style reporting via the existing conventions (name the key; positive evidence, unread shape).
